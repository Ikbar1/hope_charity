# Isi konsep dan aset

Nama Yayasan Hope Charity Indonesia, logo lampiran dan delapan nama/kunci/urutan program adalah sumber terverifikasi pengguna. Logo asli disimpan utuh sebagai public/images/hope-charity-logo.png. Header memakai public/images/hope-charity-logo-transparent.png, turunan PNG alpha 1254×1254 yang latar putihnya dihapus melalui imagegen atas permintaan pengguna 29 Oktober 2026; ukuran web tetap responsif dan rasio tidak diubah.

Prompt edit: hapus hanya latar putih menjadi alpha transparan, pertahankan simbol masjid, menara, lengkung hijau/emas, tata letak serta teks YAYASAN HOPE CHARITY INDONESIA; tanpa desain ulang. Mode: built-in imagegen background-extraction. File asli tetap dipertahankan.

resources/content/concept/id.json adalah referensi narasi mockup. en.json dan ar.json adalah terjemahan konsep untuk review, bukan naskah resmi. Sumber tiap blok adalah mockups/charity-demo; status concept diwariskan pada seluruh blok dan ilustrasi. ConceptContent memvalidasi struktur locale, status dan provenance. Tidak ada fallback bahasa; file tidak tersedia menghasilkan blok kosong.

public/images/hero-mosque.jpg, prayer.jpg, program-mosque.jpg, program-quran.jpg dan program-aid.jpg berasal dari mockup ilustrasi AI. program-quran.jpg disimpan sebagai referensi aset dan tidak dipakai sebagai kategori program baru. Foto tidak diklaim sebagai dokumentasi yayasan. Kategori tanpa foto relevan memakai simbol dekoratif.

Font lokal: DM Sans, Playfair Display, Noto Naskh Arabic berasal dari paket @fontsource, lisensi disertakan di public/fonts. Runtime tidak memanggil Google Fonts.

Untuk revisi copy, ubah JSON locale yang sama secara setara dan pertahankan key. Validasi menolak field kosong/hilang. Peningkatan concept menjadi verified membutuhkan sumber resmi serta perubahan sumber konten; terjemahan tidak meningkatkan status. Kontak resmi tetap kosong dan posting program tetap koleksi kosong. Renderer memakai PublicContentSource; sumber CMS kelak mengganti implementasi posting, bukan layout.

Local/testing/preview menampilkan konsep dengan ribbon. Production memblokir blok konsep sekalipun indexing diaktifkan. Preview Rumahweb nantinya harus APP_ENV=preview, APP_DEBUG=false dan noindex. Noindex tidak menggantikan pengendalian akses; URL serta perlindungan preview ditetapkan pada change release.
