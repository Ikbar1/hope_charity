# Demo Website Charity — Yayasan Pembawa Kebaikan

Demo statis HTML, CSS, JavaScript. Buka `index.html` langsung di browser. Tidak perlu instalasi atau server.

## Isi
- `index.html` — struktur halaman
- `style.css` — desain dan responsive layout
- `script.js` — menu mobile dan simulasi donasi
- `assets/` — potongan ilustrasi dari gambar konsep awal

## Penting untuk presentasi klien
- Angka statistik, identitas yayasan, dan teks program bersifat **contoh**, bukan data faktual.
- Foto adalah aset ilustratif sementara yang dipotong dari konsep gambar AI. Ganti dengan foto asli/berlisensi sebelum website dipublikasikan.
- Tombol donasi hanya **simulasi**, tidak memproses pembayaran.
- Ini adalah front-end demo, belum terhubung CMS, database, atau payment gateway.
- Untuk melihat font sesuai desain diperlukan koneksi internet (Google Fonts); fallback font tersedia.


## Halaman Profil
Buka `profil.html` atau klik **Profil Yayasan** di navigasi. Konten visi, misi, dan narasi masih contoh dan perlu disesuaikan dengan informasi resmi klien.
